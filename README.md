# 浏览行为看板

一个简洁的桌面端浏览历史分析工具。日历只用来选择日期；核心是通过按钮切换不同可视化，看清当天网页浏览行为。

## 运行

```powershell
npm install
npm start
```

## 测试

```powershell
npm test
npm audit --omit=dev
```

## 当前能力

- 简洁月历：只标记某天是否有浏览记录。
- 按钮切换看板：网站时长、单页占比、访问次数、时间线、明细。
- 网站浏览时长：按 domain 汇总 Chrome 原始 `visit_duration`。
- 单网页占比：按页面标题/网站汇总时长，显示占当天总时长比例。
- 网站访问次数：即使原始时长为 0，也能看到高频网站。
- 时间线网页：按访问顺序展示时间、网站、标题和原始时长。
- 原始访问明细：表格化展示，用于查证。

## 隐私边界

- 默认本地分析，不上传浏览历史。
- 不导入 `.ics`，不读取系统日历。
- 敏感标题会隐藏。
- 看板不展示完整 URL 或 query/token 参数。

# Webtrail Promo V2 Script

## Voiceover

每一次点击，都在浏览器里留下一条轨迹。

Webtrail 不把今天压成一个数字。它按二十四小时，展示当天不同时间段的访问变化。

切换天、周、月，趋势图、热力图和热门域名同步更新。

点击日历中的任意日期，所有图表立刻回到那一天。

GitHub 式热力图，把长期习惯铺成一张可以探索的浏览地图。

热门域名排行，让注意力流向一眼可见。

要找回某个页面，就按日期、域名、类型和关键词精准筛选。

所有记录永久归档在本地，不上传。Webtrail，让历史真正为你所用。
